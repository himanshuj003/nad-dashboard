# Network Anomaly Detector — Dashboard

**Web UI only** variant (Streamlit). No CLI.

Interactive analysis of network flow anomalies with synthetic data generation or CSV upload, four detectors, charts, and evaluation metrics.

## Install

```bash
cd nad-dashboard
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

Open the URL shown (usually http://localhost:8501).
